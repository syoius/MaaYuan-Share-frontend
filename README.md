## 环境变量

环境变量定义在 `.env` `.dev.development` 文件内

你可以创建 `.env.development.local` 文件来覆盖环境变量，优先级为 `.env.development.local` > `.env.development` > `.env`

可用环境变量示例：

- `VITE_API`：后端接口地址，例如 `http://127.0.0.1:8848`
- `VITE_THERESA_SERVER`：地图站地址
- `VITE_SIMING_BASE_URL`：MaaYuan-SiMing 生成器服务地址
- `VITE_USE_REG_CODE`：是否启用“注册码注册”模式（`true`/`false`，默认 `false`）。启用后注册页将显示“注册码”输入框并隐藏“发送验证码”按钮，注册请求体将携带 `registrationCode` 字段；关闭时沿用邮箱验证码流程，注册请求体携带 `registrationToken` 字段。
- `VITE_SITE_RETIRE_HOST`：域名迁移一次性提示弹窗的触发域名（如 `share.maayuan.fun:16666`）。仅当访问 host 命中时弹出；留空则关闭该提示。同一份代码部署到其他域名（新地址）不会弹出。
- `VITE_SITE_RETIRE_DATE`：上述提示中展示的保留截止日期文案（如 `2025年12月31日`）。
- `VITE_SITE_RETIRE_TARGET`：上述提示中建议用户使用的新地址（如 `https://maayuan.top`），按钮点击后直接跳转。

## 快速编辑与分享图片

快速编辑悬浮窗会将初始敌方站位、主位、动作目标及阵亡/增援记录保存到作业顶层 `recorder_meta`；旧作业没有该字段时沿用默认五人站位。分享图使用这些记录为动作配色并展示敌方站位，支持按操作或单元格标色、编辑敌方名称、富文本回合备注，以及标记必须/禁用命盘。回合备注保留允许的文字格式，粘贴仅接收纯文本，编辑区不接受拖入内容。

备注编辑画布保持浅色，与导出图片一致，保证红字、蓝字在深色主题下仍可辨认。默认开发 API 为 `https://share.maayuan.com/api`，大陆构建仍使用当前域名的 `/api`。

## 创建作业的关卡排序

editorv2 关卡下拉列表使用后端已有的 `endTime`，每次打开时重新判断截止状态：未截止关卡按截止时间升序排列，无截止时间或时间无效的关卡居中，已截止关卡按截止时间降序排列。截止时刻本身仍视为未截止；没有开始时间时，未来关卡也归入未截止。

截止时间相同时沿用“分类 → levelId → stageId”排序。分类菜单保留原顺序，输入关键词时仍按搜索匹配度排序，已截止关卡仍可选择。

## 作业网格卡片

网格卡片按标题、关卡与来源、所需密探、说明摘要、作者与统计、操作按钮的顺序展示。密探头像、姓名、星级及血攻按列对齐；未提供的星级留空，血攻显示「—」，不作为零值处理。分组直接展示候选密探。

固定密探和分组候选均未填写星级、血量或攻击时，隐藏逐人占位行，仅显示一次「未提供星级及血攻要求」；部分已填写时仍保持属性对齐，明确填写的零值继续展示。匹配状态显示「密探已匹配」，悬停或使用屏幕阅读器可获取「仅核对密探持有名单，不校验练度」说明。

配色调整限定在作业卡片（`.operation-card`）：米鸢主题下使用奶油色底色（`#FFF8EC`）和 1.5px 暖棕色外边框（`#B69A74`），悬停或卡片内控件获得键盘焦点时边框加深为 `#8F673C`，配合轻阴影增强轮廓。内部细分隔线和次要按钮仍使用浅砂色（`#D8C9B3`）。页面背景、筛选区和创建区沿用原主题。关卡标签以「分类 | 关卡名称」展示，分隔符两侧保留固定间距。

说明摘要最多显示三行，长网址在摘要中显示为「原文链接」；点击「查看完整说明」打开作业详情，完整内容保持原样。原文入口优先使用元数据中的转载地址，否则使用说明中的首个 HTTP(S) 链接，并在新窗口打开。底部保留下载与加入作业集，突出「复制代码」；关闭 JSON 下载偏好时隐藏下载按钮，多选模式仍显示选择按钮。原创标签使用静态配色。传统列表模式保留原布局。

摘要识别已知的小红书分享标题包装、链接、分享口令及打开 App 的提示，将正文放在分享标题之前。分享标题仍作为补充保留；只有分享标题时以标题作为摘要。其他平台或无法确定的文本保留，详情及导出内容不改写，完整原文地址仍由原文入口提供。

## YuanHub 密探匹配

作业列表「密探匹配设置」接入 YuanHub 独立的作业匹配连接（`ymatch_`），一个连接码可切换本人的全部游戏子账号。原有 MaaYuan 同步连接和手动 Box 筛选保持原用途。

| 设计约束 | 实现 |
| --- | --- |
| 最多 5 人，无助战 | 固定密探与分组都占一个位置；二分匹配保证每人最多占一个位置 |
| 按真实账号档案判断 | 明确选择账号；校验连接 ID、账号 ID、游戏；切换立即停用旧档案，取消过期请求 |
| 仅按持有名单筛选 | 开启后只显示当前账号拥有且未设为「不使用」的密探能组成阵容的作业；不比较等级、修为、化极、攻击、生命、命盘或星石 |
| 阵容信息不完整 | 作业未填写阵容、包含空分组或所需密探无法识别时，不纳入匹配结果 |
| 凭据与缓存 | 连接码保存在本浏览器 localStorage，通过本站后端只读转发；连接码、最新选中档案和筛选设置按本站用户隔离，档案带连接/账号/游戏标识，不跨用户复用 |

刷新后自动恢复连接码和标明本站同步时间的本地档案；每次打开设置时自动同步账号列表和当前账号的档案，也可点击游戏账号旁的「刷新档案」手动同步。同步期间暂停匹配，成功后恢复原开关状态；失败时保留本地档案并停用匹配。连接码使用浏览器本地存储，并非加密保管。点击「断开并清除本地数据」会一并清除连接码、档案和筛选设置，不撤销 YuanHub 连接。撤销需到 YuanHub 个人中心；其效果是禁止后续读取，已缓存副本由用户自行清除。

弹窗将只读连接状态、游戏账号和匹配开关分组展示；已连接时收起连接码，通过「更换连接码」编辑，新连接和档案读取成功后才替换当前数据，取消或验证失败保留原连接及匹配设置。首次连接成功但没有游戏子账号时显示添加账号提示。同步中显示暂停匹配的状态，失败保留缓存档案并关闭匹配，重试成功后可手动重新启用。开关区仅显示「启用匹配」和开关，即时生效，无需另行保存；刷新和切换游戏账号保留原开关状态。弹窗沿用本站主题配色，米鸢主题使用米色背景、暖棕文字与砂色按钮；「更换连接码」「刷新档案」使用浅底描边按钮；底部「断开并清除本地数据」使用浅红底描边按钮，需确认后执行，不撤销 YuanHub 授权。输入弹窗不支持点击遮罩关闭，可通过关闭按钮或 Esc 退出。

启用密探匹配或切换游戏账号时，作业列表会自动选择该账号的「如鸢」或「代号鸢」筛选；之后仍可手动调整，关闭匹配时保留当前筛选。

「密探匹配设置」内点击「不使用的密探」选择框即可展开当前账号的已拥有密探头像面板，也可输入名字或别名搜索；点击头像勾选为「不使用」，再次点击可恢复使用。已拥有但未养成的密探也可手动排除。选择即时参与匹配，不改写 YuanHub 档案或本地原始档案；作业必须使用被排除的密探时不纳入结果，候选分组仍会尝试其他可用密探。名单按本站账号、连接、游戏账号及游戏版本隔离，刷新或同步档案后保留；已选标签自动换行，最多显示约三行，超出时在选择框内滚动；可移除单个标签，或通过唯一的「清空选择」按钮恢复全部使用。断开并清除本地数据时一并清除。原有「只看/排除密探」仍按作业内容检索，不将这份「不使用」名单发送为后端查询条件。

匹配只针对已经加载的作业，最多自动补载 5 页；可继续手动加载，显示数量不是全站总数，也不保证通关。筛选栏在「启用匹配」开关右侧以次要文字显示「当前匹配 N 份」，关闭匹配时隐藏数量；卡片上方不再显示加载统计和长说明，继续查找的提示放在列表底部「加载更多」按钮上方。不再提供四种状态筛选；旧设置中的状态选择自动忽略，已保存的连接、开关和按账号排除名单继续保留。持有名单中有记录且未明确标记为未拥有的密探视为已拥有，练度不足由用户在「不使用的密探」中排除。

### 本地对接

生产 `.env` 保持不变。本机 `.env.development.local` 使用：

```dotenv
VITE_API=/api
DEV_API_PROXY=http://127.0.0.1:8848
VITE_YUANHUB_URL=http://127.0.0.1:61198
```

Vite 仅在设置 `DEV_API_PROXY` 时代理 `/api` 并去掉该前缀。Share 后端开发配置中的 `yuanhub.matcher.base-url` 指向本机 YuanHub 后端（本机当前端口 61199，可用 YuanHub `./dev.sh --print-env` 查看）。生产默认域名不变。切换后端后重新登录本站，旧环境的登录凭据不通用。

定向检查：`npx vitest run src/models/operatorMatcher.test.ts src/apis/yuanhub.test.ts src/store/operatorMatcher.test.ts src/components/OperatorMatcher.test.ts src/components/Operations.matcher.test.ts`。存储测试覆盖刷新恢复、本站账号隔离、按游戏账号保存不使用名单和清除行为。桌面/手机布局与本地交互可通过浏览器验证；真实 YuanHub 账号切换与通关效果仍需实机验收。

## 搜索与筛选

游戏标签通过 `tags` 重复查询参数发送，后端按 AND 条件过滤后分页；前端不再逐页下载后筛选标签。API 客户端尚未生成该字段时，由 `OperationApi.queriesCopilotRequestOpts` 补齐序列化。

首页热度屏蔽表仅用于无搜索条件的热度浏览。关键词、神秘代码、关卡、作者、标签或密探筛选不受该表影响；神秘代码仍只按 ID 查询。

关卡弹窗可直接输入文字后点击「搜索」，无需选中下拉项；选择候选关卡则按其 ID 精确筛选。取消不提交草稿，重新打开恢复当前条件；清空后搜索或点击「重置」清除关卡条件。作业集及关卡兜底搜索中的正则特殊字符按普通文字处理，需要同步更新后端。

列表读取原始响应以保留元数据，但仍校验 HTTP 和业务状态；查询失败显示错误，不显示为正常的空结果。

搜索回归：`yarn test src/apis/operation-search.test.ts src/components/editor2/LevelSelectDialog.test.ts`。

搜索输入仍保留 500 毫秒防抖；按回车会立即提交当前关键词，不再等待剩余防抖时间。中文输入法确认候选时的回车不会触发提前提交。
